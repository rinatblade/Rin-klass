# Rin-klass

Android-приложение: скачивает анимированные подарки с «Одноклассников» в GIF (в галерею)
и делает из них анимированные стикеры для WhatsApp.

- Встроенный браузер с «Ловцом»: анимированные подарки обводятся пунктиром, нажатие — скачивание в GIF.
- Раздел «Подарки» — все скачанные GIF; из любого можно сделать стикер.
- Раздел «Стикеры» — наборы WhatsApp (анимированные, 512×512, до 500 КБ).
- 20 цветовых тем и выбор шрифта, фоновый режим со значком в шторке.

Сборка: GitHub Actions (`Build APK`), готовый файл — в Releases (`Rin-klass.apk`).
